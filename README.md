# Video-Delta-E-Analyzer

**基于 Python 的视频色差（ΔE）分析与自动截帧工具**

本项目提供三个基于 Python 的视频处理程序，主要用于从实验视频中提取颜色信息，实现动态颜色变化的定量分析。

该工具面向比色传感、刺激响应材料及其他涉及颜色变化的实验研究，支持自定义感兴趣区域（Region of Interest, ROI）、定时采样、CIE76 色差计算和 Excel 数据导出。

## 1. 主要功能

- **时间分辨比色分析**：支持每隔 1 秒或 10 秒提取一次视频颜色数据。
- **交互式 ROI 选择**：直接在视频预览窗口中框选需要分析的区域。
- **自动计算 ΔE**：以视频初始帧为参考，使用 CIE76 公式计算不同时间点的色差。
- **Excel 数据导出**：自动记录采样时间、RGB、CIELAB 和 ΔE 数据。
- **自动视频截帧**：支持每隔 1 秒从 AVI 视频中提取一张 PNG 图片。
- **自定义采样间隔**：可通过命令行参数调整色差数据的采样频率。

## 3. 环境配置

### 3.1 运行环境

需要安装 Python 3，以及以下 Python 库：

- OpenCV：用于视频读取、图像处理与 ROI 交互选择。
- NumPy：用于数值计算和颜色空间转换。
- OpenPyXL：用于生成与编辑 Excel 文件。

### 3.2 安装依赖

在终端运行：

`pip install opencv-python numpy openpyxl`

其中，视频截帧程序仅需要 OpenCV。

## 4. 使用方法

### 4.1 每隔 1 秒提取 ΔE

运行：

`python delta_e_1s.py "D:\Videos\experiment.avi"`

程序启动后，将打开视频预览窗口。

**操作方式：**

| 操作 | 功能 |
|---|---|
| Space（空格键） | 播放或暂停视频 |
| 鼠标左键拖动 | 框选感兴趣区域 ROI |
| Enter（回车键） | 确认 ROI 并开始分析 |
| Esc | 取消操作 |

**处理流程：**

1. 读取视频并打开预览窗口。
2. 用户手动框选需要分析的 ROI。
3. 程序记录 ROI 的位置和尺寸。
4. 从视频 0 秒开始，每隔 1 秒提取对应帧。
5. 计算每个时间点 ROI 内的平均 RGB 值。
6. 将平均 RGB 转换为 CIELAB 颜色空间中的 L*、a*、b*。
7. 以第一帧为参考，计算各时间点的 ΔE。
8. 将分析结果自动导出为 Excel 文件。

**注意：** ROI 可以在视频预览过程中的任意一帧选择，但正式的数据分析始终从视频 0 秒开始。

### 4.2 每隔 10 秒提取 ΔE

运行：

`python delta_e_10s.py "D:\Videos\experiment.avi"`

程序操作方式与 1 秒采样版本相同，区别仅在于默认采样间隔为 10 秒。

适用于实验时间较长、颜色变化相对缓慢或不需要高时间分辨率的实验视频。

### 4.3 自定义采样时间

两个色差分析程序均支持通过 `--interval` 参数修改采样间隔。

例如：

`python delta_e_1s.py "D:\Videos\experiment.avi" --interval 5`

表示每隔 5 秒提取一个数据点。

### 4.4 每隔 1 秒自动截取视频图片

运行：

`python frame_extractor_1s.py "D:\Videos\experiment.avi"`

该程序适用于 AVI 格式的视频。

运行后，程序将：

1. 读取用户指定的视频文件。
2. 根据视频帧率确定各整秒对应的视频帧。
3. 每隔 1 秒保存一张 PNG 格式图片。
4. 在原视频所在目录中自动创建独立的输出文件夹。
5. 以视频时间戳为每张截图命名。

**输出文件示例：**

- `00_00_00.png`
- `00_00_01.png`
- `00_00_02.png`
- `00_00_03.png`

文件名采用 `时_分_秒.png` 格式。

如果同名输出文件夹已存在，程序会自动为新文件夹添加序号，避免覆盖原有数据。

## 5. 色差计算原理

本程序采用 CIE76 色差公式，即 CIELAB 颜色空间中的欧氏距离。

**ΔE*ab = √[(ΔL*)² + (Δa*)² + (Δb*)²]**

其中：

- **L***：明度，描述颜色的明暗程度。
- **a***：绿—红颜色轴。
- **b***：蓝—黄颜色轴。
- **ΔL***：当前帧与参考帧之间的明度差。
- **Δa***：当前帧与参考帧之间的 a* 差值。
- **Δb***：当前帧与参考帧之间的 b* 差值。

### 5.1 RGB 至 CIELAB 转换

程序首先计算 ROI 内所有像素的平均 RGB 值，再按照以下流程转换颜色空间：

**平均 RGB → 线性 RGB → XYZ → CIELAB**

转换过程中采用 sRGB 色彩模型及 D65 标准白点。

需要注意，程序使用的是“先计算平均 RGB，再转换为 Lab”的方法，并非逐像素转换为 Lab 后再求平均值。

### 5.2 参考帧设置

程序默认将视频 0 秒处的第一帧作为参考帧，其色度坐标记为：

**L₀*、a₀*、b₀***

后续每个采样时刻的颜色数据均与该参考帧比较。

因此，初始时刻满足：

**ΔE(0) = 0**

程序最终得到 ΔE 随时间变化的数据，可用于绘制动态颜色响应曲线。

## 6. 数据输出

### 6.1 Excel 文件

色差分析程序默认生成：

`video_name_DeltaE_CIE76.xlsx`

文件保存在原视频所在目录，包含两个工作表。

**Results：实验数据**

| 数据列 | 说明 |
|---|---|
| Target time (s) | 目标采样时间 |
| Frame time (s) | 实际视频帧对应时间 |
| Frame index | 视频帧序号 |
| Mean R | ROI 平均红色通道值 |
| Mean G | ROI 平均绿色通道值 |
| Mean B | ROI 平均蓝色通道值 |
| L* | CIELAB 明度值 |
| a* | CIELAB 绿—红轴坐标 |
| b* | CIELAB 蓝—黄轴坐标 |
| DeltaE (CIE76) | 相较于初始帧的色差 |

**Settings：分析参数**

记录内容包括：

- 视频文件路径
- 参考帧信息
- 采样间隔
- 视频帧率
- 视频总帧数
- 颜色空间转换方法
- 色差计算公式
- ROI 的坐标与尺寸

导出的数据可以直接用于 Origin、Excel 或其他数据分析软件，进行曲线绘制和后续分析。

## 8. 应用领域
本项目主要用于涉及动态颜色变化的实验研究，包括：

**比色气体传感器**：提取传感材料在气体暴露过程中的颜色变化。
**光学化学传感器**：分析颜色随待测物浓度或作用时间的变化。
**刺激响应材料**：研究材料在外部刺激下的动态颜色响应。
**颜色响应动力学**：获取 ΔE–time 曲线，辅助分析响应与恢复过程。
**视频图像分析**：对固定区域的颜色变化进行定量追踪。

## 9. 注意事项与局限性

1. ROI 在整个分析过程中保持固定位置，不会自动追踪移动的样品。
2. 无论在哪一帧选择 ROI，程序均以视频 0 秒处的帧作为参考。
3. 采样过程根据视频标称帧率定位，因此实际帧时间可能与目标采样时间存在微小偏差。
4. 环境光照、拍摄角度、相机曝光、自动白平衡和视频压缩均可能影响颜色测量结果。
5. 基于普通视频计算的 ΔE 反映所记录图像中的颜色差异，不能直接等同于经过专业色度仪校准的测量结果。
6. 当前程序未集成颜色校准、光照补偿或样品自动追踪功能。
